registries, not a new native timing campaign. The S3 source artifacts are
generated by the pinned S3 candidate. The lab independently checks their paths,
report kinds, SHA-256 values and common candidate HEAD. It does not claim
independent compiler execution or performance measurement.

```text

  had known origins and NO_ESCAPE. Static, diagnostic-only; no transformation.

  Three codegen reports with Assembly-op to emitted-assembly-text spans.
  34.6%-39.3% mapped; remainder explicit UNMAPPED. Binary .text unavailable.

  human-authored samples. No normalization claim.
```

## Cross-version and measurement limits

The cross-version index carries S3 1.7 static ELF disassembly metrics and S3
1.8 emitted assembly text plus Assembly-origin spans. The artifact scope, unit
and extraction protocol differ, so:

```text
DIRECT_DELTA_SUPPORTED=NO
RUNTIME_TIMING=NOT_MEASURED
PMU=UNAVAILABLE
NATIVE_SPEEDUP_CLAIM=NO
```

The 1.8 generated assembly text byte counts are not object `.text` size.
Stack-resident virtual values are not dynamic spills. No static metric is
promoted to a runtime event or cost model.
